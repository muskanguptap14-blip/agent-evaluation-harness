Agent Eval Harness App Map

This tool is a local Python harness that turns an AI-coded task into a visible evaluation report: it validates input, runs the project in a sandbox, runs pytest, and prints a pass/fail matrix with token usage.

Flow:
prompt or challenge file → agent_eval/cli.py → agent_eval/models.py → sandboxed project → agent_eval/evaluator.py → pass/fail matrix + summary

What the app does

  • Accepts a quick prompt or a JSON challenge file.
  • Validates the challenge data with Pydantic models.
  • Copies a local sample project into a temporary sandbox.
  • Runs pytest and records results for each requirement.
  • Prints a readable summary: pass/fail count, requirement matrix, and token usage.

To change the evaluation behavior, start here
  • Update agent_eval/evaluator.py to change how results are computed and mapped to requirements.
  • Update agent_eval/runner.py to alter how the project is copied or tested in the sandbox.
  • Update sample_project/test_cleaner.py to try a different test or edge case.

Practice to reuse

Define the observable result before building the mechanism. In this project, the requirement-by-requirement scorecard made the check explicit: the app didn't just say “pass” or “fail,” it linked the result to a real requirement and a real test signal.

How to run it again

python -m agent_eval --challenge challenges/sample.json --project sample_project
